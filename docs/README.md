## 要件の扱い

以下は、2026年11月4日に共有された「キックオフスライド11/2修正版PDF＋Discord運営回答」のまとめをもとにした確認事項です。原本との照合は未実施です。公式資料・回答のURLは入手後に追記し、追加告知があれば更新します。

- テーマは **Own the Why, Build with Intent.** 人間が目的と判断の根拠を持ち、AIの提案の採否を決める。
- 世界の課題・社会課題を解決すること。「誰の・どんな課題か」を根拠付きで具体化する。
- カテゴリは **医療・福祉／観光／教育／エンターテインメント／クリエイティブ** のいずれかが必須。SDGs 17目標への当てはめは必須ではない。
- **Googleテクノロジー／Geminiを中核に活用**し、目的に対して採用する理由を説明する。
- 実行基盤は **App Engine／Compute Engine／GKE／Cloud Run／Firebase App Hosting／Firebase Hosting** のいずれか1つ以上が必須。
- AIを使う場合はVertex AI経由が推奨。Google AI StudioはCloudクレジット対象外（無料枠は可）。他社LLMの内部利用は禁止されていないが、Google技術としては評価されない。他社AIがメインのプロダクトは対象外で、デモやピッチでも他社製品を前面に出さない。
- 採用案だけでなく、比較した案・採用しなかった案とその理由、メリット・デメリットを記録する。
- AIをどの場面でどう使い、なぜそこで使ったか、開発を通して何を得てどれだけ成長したかは、採点外でも必須記入。

## 評価基準

次の8項目を各0〜3点、合計24点で評価する。アイデア段階で点数や達成を断定せず、デモ・調査・設計判断で説明できる材料をそろえる。

| 分野 | 評価項目 | 各案に残す材料 |
| --- | --- | --- |
| Google技術の活用 | Google技術が中核で有効に機能するか | 中核の処理とGoogle技術の役割 |
| Google技術の活用 | 採用理由が合理的・具体的か | 候補比較、選定理由、メリット・デメリット |
| プロダクトの完成度 | 必要な操作が一連の流れとして動くか | 最初から結果までの操作フローとデモ |
| プロダクトの完成度 | 対象ユーザーが目的を達成できるUI・UXか | 対象者による操作確認と改善点 |
| プロダクトの完成度 | 安全性・拡張性・保守性を意識しているか | 扱うデータ、失敗時の動作、構成の理由 |
| 社会課題への解決力 | 課題が具体的・明確か | 対象者、困る場面、出典やヒアリング |
| 社会課題への解決力 | 機能・仕組みが課題解決に有効か | 検証方法、結果、限界 |
| ピッチの構成と説明力 | デモと構成が明快でインパクトがあるか | 課題→操作→結果→根拠の説明 |

## 共通チェック

採用する案で確認し、提出用の公式テンプレートにも反映する。

- [ ] 対象カテゴリと社会課題が明確で、根拠の出典を示せる。
- [ ] Google技術が中核で動き、指定実行基盤を1つ以上使っている。
- [ ] 技術の選定理由・メリット／デメリット・採用しなかった案を記録した。
- [ ] AIの利用場面・使い方・その理由と、人間が判断した内容を記録した。
- [ ] 開発を通じた学びと成長を実績に基づいて記録した。
- [ ] デモは実際に動作する内容を使い、偽装や未実装機能の誤認を避ける。
- [ ] APIキー・秘密情報をコミットせず、素材・ライブラリ・データの出典とライセンスを著作物利用シートに記載した。
- [ ] 不適切な内容やルール違反がなく、GDG行動規範を守っている。
- [ ] GitHub、公式プロダクト説明ドキュメント、デモ動画（オンラインはプレゼン動画）、著作物利用シート、ピッチ用スライド（現地のみ）をそろえた。
- [ ] 会場別GoogleフォームへGitHub URLとDriveフォルダURLを提出し、Driveを「リンクを知っている全員が閲覧可」にして別環境でも開けることを確認した。
- [ ] デプロイURLを11月14日まで稼働させる準備ができている。

## 日程と開発の制約

時刻は日本時間。共有された要件に基づく。

- **11月5日10:00まで**：ソースコード、IaC、CI/CD、フレームワーク初期化は禁止。環境整備、PoC（本番リポジトリへ流用不可）、デザインツールでのUI作成は可。ここでは検討文書だけを扱う。
- **11月5日10:00〜11月10日19:00**：開発期間。11月10日19:00にコードフリーズ・提出締切。以降Regional Day終了までリポジトリを変更できない。
- **11月11〜13日**：事前審査。20チーム超の会場は上位約20チームに絞り、ピッチ進出は11月13日通知。
- **11月14日**：Regional Day。現地ピッチ進出チームは最低1名が現地参加。**Regionalのピッチ時間は共有情報では未確定**で、追加告知を確認する。オンラインはピッチなしの書類審査で、決勝進出発表は11月15日。
- **11月27日**：Demo Day。決勝進出チームのみ追加開発可。発表5分＋質疑1分の6分、Demo-first。Regionalと評価観点は共通だが点数は持ち越さない。
- Cloudクレジットは1チーム20ドル。候補技術の料金を確認し、予算アラート、不要なVM・GPUの停止、APIキーの利用制限を検討する。

## この文書でのAI利用

要件の構造化、テンプレート作成、各案の検討用仮説の下書きに生成AIを利用した。案を同じ項目で比較し、未確認事項を整理するため。カテゴリ・課題・技術・機能の採否はチームが判断する。実装や検証におけるAI利用実績と、開発を通じた学び・成長は開発後に追記する。
