- 解決したい社会課題（仮説）: 未確定。死亡例を知ること自体が、誰のどの課題を改善するかを先に確認する。

- 人間が決める意図: 刺激の強さや毎日の利用を目的化せず、本人にとって何を得られる体験にするかを決める。

## 3. What：解決策と最小の体験

- 解決の仕組み（仮説）: 出典を示せる同年齢の事例を、生活や価値観を振り返る問いとともに任意で読む。具体的な「体験」の形式は要確認。
- 操作フロー案: 内容の説明を読む→閲覧するか選ぶ→出典付きの事例と問いを見る→終了・中断する。
- MVP候補: 許諾・出典を確認できる少数の事例、閲覧前の説明、中断・非表示、振り返りの問い。
- 今回の対象外候補: 強制的な毎日の通知、刺激的な再現、個人の死亡リスクや余命の推定。
- 既存の手段との差（仮説）: 記事や統計を読む行為より振り返りに役立つか、負担が増えないかを確認する。
