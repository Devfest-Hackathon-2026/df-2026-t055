# Cloud Storage JSON API 接続の実装監査

- 対象: #29 のStorageポートと実際のGoogle認証済み接続。先行PR #110 とFirestore接続PRに依存。
- API操作: ADCを使用し、アップロード、世代一致読み取り、世代一致コピーをJSON APIの条件付きリクエストへ対応させる。返却された世代は文字列として検証する。
- Node Storage SDKの世代の数値変換を避け、2^53を超える世代も文字列で送る。エラーの詳細を外部へ返さず、権限・世代条件に失敗した場合は閉じる。
- 検証: リクエストの条件・大きな世代・ストリーム・認証設定・エラー処理をモックでテスト。全体テスト、ビルド、型検査を実行。
- 未検証: 実際のGCPバケット、ADC、IAM、ネットワーク障害時の実サービス挙動。バケットとサービスアカウントは別途設定が必要。本番起動ガードは残る。
- 依存関係のnpm auditはFirestore接続PRと同じ中程度4件が残る。
