# MVPの範囲とデモ作業

主作業は **タオルの折りたたみ→のし紙巻き→袋入れ→テープ止め→仕上がり確認** とする。就労継続支援B型「るる藤沢」がタオル折り、紙巻き、袋入れ、テープ止めの一連の作業を紹介している。[事業所による作業紹介](https://www.ruru.co.jp/ruru-fujisawa/work-details/)

チームが撮るのは、この作業をもとにしたデモ用の手本である。事業所固有の納品規格を再現する教材とは分ける。材料は家庭のフェイスタオル、無地の帯紙、透明袋、テープ。手持ち品を優先し、追加購入の上限を1,000円とする。加熱器具と刃物は使わず、紙は撮影前に裁断する。顔・名札・顧客情報を映さず、チームの手元と声だけを収録する。

## 手本の撮影台本

| 順番 | 動作 | 動画で残す情報と声かけ |
| --- | --- | --- |
| 1 | タオルを広げて向きとしわを見る | 全体を見てから手を置く。「先に広げよう」 |
| 2 | 長辺を合わせて半分に折る | 片手で端を押さえ、もう片方を動かす。「ここを押さえて」 |
| 3 | 端をそろえてもう一度折る | 押さえる手を持ち替え、折り目をなぞる |
| 4 | 帯紙の中央へ置く | 向きを決めてから載せる。「真ん中に置こう」 |
| 5 | 紙の片側を押さえ、反対側を巻く | 紙が戻りかけた時の押さえ直しと待つ間。「押さえたまま、こちらを巻くよ」 |
| 6 | 袋の口を開き、タオルを差し込む | 袋を開く手と入れる手の順番。引っ掛かったら止めて口を広げ直す |
| 7 | 紙のずれと袋内の位置を直す | 封をする前に一拍置いて見る。「閉じる前に見よう」 |
| 8 | 袋口を折り、テープで止める | 袋口を押さえてからテープを貼る |
| 9 | 仕上がり見本と比べる | 紙の向き・袋口・テープを順に見る。困ったら「手伝って」を使う |

工程の区切りは「折る」「巻く」「入れる」「封をする」で手の役割が変わる位置に置く。単に完成形の写真を並べると、紙を押さえたまま巻く順番、袋が引っ掛かった時の戻し方、封の前の待ちが伝わらない。声かけを動作の時点と結び付けるため、動画解析を使う。

撮影担当は11/8午前に90〜150秒の手本を1本撮り、各動作と声かけが入ったことを再生して判定する。動画の必要性は[受入条件](../validation/acceptance.md)の同一作業比較で判定する。封筒へのチラシ封入は写真数枚との比較用に残す。

MVPは1組織相当のデモ環境、1作業、架空の本人プロフィール2件、職員・本人・新人の3画面系統とする。本人向けは「写真のみ」または「写真と短文」で一度に1工程を示す。読み上げはどちらの表示方法でも本人が希望すれば併用できる。承認のタイミングで承認済み短文から事前生成する形に限り、「あれば枠」の筆頭として扱う。実行時にその都度生成はしない。診断からの推定、作業速度による採点は対象外とする。
