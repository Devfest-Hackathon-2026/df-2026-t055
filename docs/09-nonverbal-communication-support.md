# 声・身振りから意思確認を支える

- 投稿: 会話内で提起された案（特定の個人の事例ではない）
- 状態: 保留・未検証

## 1. 元の案

発語による意思表出が難しい人の声や振る舞いについて、長く関わった職員が経験から理解していることを、新人にも引き継げないか。食事・排せつ・不快さなどで表現が違う可能性を想定した。

## 2. Why：誰の、どんな課題か

- カテゴリ候補: 医療・福祉。
- 対象・課題の仮説: 本人の表現に慣れていない職員が、何をどう確認すべきか分からない。
- 根拠: [意思決定支援ガイドライン](https://www.mhlw.go.jp/stf/newpage_76171.html)は言葉以外の反応の記録と仮説的な検討を重視する。声と意思に安定した対応があるかは未確認。
- 意図: 担当者が変わっても、本人への確かめ方を引き継ぐ。

## 3. What：解決策と最小の体験

- 候補: 既存の具体例と対応・本人の反応を検索し、職員が似た場面で確認する。
- 操作案: 場面を入力→関連する過去例と出典を見る→本人に確認→結果を記録する。
- 対象外: 声だけで本人の意思を確定する機能、全利用者に共通する分類器。

## 4. How：Google技術と候補比較

- 候補: Geminiで記録の整理・関連例の抽出、Cloud Runで実行。未採用・未実装。
- メリットの仮説: 自由な記述から関連例を探せる。
- デメリット: 誤った関連付け、個人別データの不足、記録の偏り。
- 比較対象: 既存の記録ソフト、紙の引き継ぎ、ベテランへの相談。ルールによる参照で足りる可能性もある。

## 5. AIをどこで、なぜ使うか

- 過去例を整理・参照する補助に限定する案。職員の解釈も正解と決めない。
- 人間が確認すること: 観察した事実、解釈、確認方法、本人の反応を分ける。
- 文書整理・調査でのAI利用は[共通記録](intellectual-disability-welfare-review.md#ai利用と判断)を参照。

## 6. 検証・完成度・デモ

架空例で検索・表示は試せるが、実際の本人の意思を読み取れる精度や利益は示せない。本人別のデータ、利用条件、確認方法が必要。データの公開や常時録音を前提にしない。

## 7. 未決定事項・次の確認・学び

### 選定しなかった理由

- 個別対応が必要なことと、データから意思を分類できることは別。
- ベテランの推測を教師データの正解にすると、誤解を固定するおそれがある。
- 発声・行動は場面や関係性で変わり得る。本人への確認を省略する根拠はない。
- 記録入力と結果確認が新たな負担にならないか未確認。

再検討条件: 実際に困る一場面、現在の確認方法、共有可能な情報を把握できること。学びは推定の自動化と意思確認の支援を区別する必要があること。開発による学びは未記入。
