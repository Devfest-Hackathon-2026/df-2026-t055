# 本人に合わせた作業手順の提示

- 投稿: 壁打ちで具体化した案
- 状態: 検討候補として残す。開発する案の最終決定と、効果の検証は未実施。

## 1. 元の案

Geminiで職員の手本動画を解析して作業工程を整理し、本人に合った写真・短文・音声の手順を作る。本人向けの説明方法や教え方の工夫も新人職員へ引き継ぎ、同じ試行錯誤を繰り返す負担を減らすことを目指す。例として封筒にチラシを入れる作業を想定した。

## 2. Why：誰の、どんな課題か

- カテゴリ候補: 医療・福祉。
- 対象・課題の仮説: 写真などを参照できると作業しやすい本人と、その人に合う教え方を引き継ぐ職員。特に新人が説明方法や工程の区切り方を一から試行錯誤する負担を想定する。
- 根拠: [厚労省の事例集](https://www.mhlw.go.jp/content/11600000/001230884.pdf)に写真・図や工程分割の実践がある。想定する現場で動画から作る必要があるかは未確認。
- 意図: 本人が望む作業を進められる場面を増やす。説明の準備や新人の試行錯誤にかかる時間を減らし、職員が支援に使える時間の余裕につなげたい。時短や支援時間の増加は、今後検証する効果の仮説である。

## 3. What：解決策と最小の体験

- 操作案: 職員が手本と説明を撮影→Geminiが工程と説明を下書き→職員が本人に合う提示方法や声かけを確認・修正→新人が教え方と手順を確認→本人への支援で使い、使いにくい部分を修正する。
- 個人に合わせる内容の候補: 一度に示す工程の数、写真・短文・音声の使い分け、職員が確認した声かけや説明の工夫。診断名だけから自動で決めない。
- MVP候補: 1作業、動画からの工程整理、本人に合わせた写真と短文の手順、職員の編集、新人が教え方を確認する画面、本人の「手伝って」「やめる」。
- 対象外: 全利用者への自動最適化、未確認の生成手順の自動公開。

## 4. How：Google技術と候補比較

- 候補: GeminiをVertex AI経由で使い、動画・画像から工程と説明を整理する。Cloud Runでアプリを動かす。構成の確定と実装は未実施。
- メリットの仮説: 動画から工程と説明の下書きを作り、職員が確認した本人向けの調整を新人も参照できる。
- デメリット: 工程の抜け、誤った写真・説明、撮影・修正の負担。
- 比較対象: 直接教える、写真数枚を並べる、汎用AI、[MagnusCards](https://www.magnusmode.com/magnuscards/)。

## 5. AIをどこで、なぜ使うか

Geminiを動画の解析、工程の分割、説明の下書きに使う案。本人への提示方法や新人に引き継ぐ工夫は、職員が確認して決める。文書整理・調査でのAI利用は[共通記録](intellectual-disability-welfare-review.md#ai利用と判断)を参照。

## 6. 検証・完成度・デモ

- 比較するもの: 準備・撮影・修正を含む作成時間、新人が教え方を確認する時間、説明や試行錯誤を繰り返す負担。直接説明、写真の手順、汎用AI、既存の手順作成サービスと比較する。
- 本人への確認: 手順や説明が使いやすいか、必要な支援を求められるかを確かめる。作業完了の速さだけを本人の利益としない。
- デモ案: 同じ作業の手本動画→Geminiによる工程の整理→職員が本人向けに調整→新人が教え方を確認する、という流れを見せる。動画から表示までの変化とGoogle技術の役割を説明しやすい。
- 未検証の効果: 新人の試行錯誤の削減、職員の時間の余裕、本人への支援の改善。デモで一連の操作が動いても、これらを実証したことにはならない。

## 7. 未決定事項・次の確認・学び

### 候補として残す理由

- Geminiの動画解析から本人に合わせた手順を提示する流れが、作業の説明や教え方の引き継ぎに使える可能性がある。
- 新人が説明方法を何度も試す負担を減らし、職員の時間の余裕につながる可能性を検討したい。
- 動画の入力、工程の整理、本人向けの調整、新人への提示を、一つのデモで説明できる。
- 撮影・確認の負担や既存製品との重複は確認事項として残し、それだけを理由に候補から外さない。

### 残っている確認事項

- 直接教える方法や写真数枚で足りる場面と、動画解析・個人に合わせた調整が役立つ場面の違い。
- 撮影と修正の手間を含めても、繰り返しの説明や新人の試行錯誤を減らせるか。
- 既存の手順作成サービスや汎用AIと比べ、何が使いやすくなるか。
- 動画に現れない本人の好みや教え方の工夫を、職員がどう確認・補足するか。

開発による学びは未記入。今後の検討候補として残し、効果は検証して判断する。
