# 運動の習慣化アプリ

- 投稿: Koki🍙(ちよ)18:14
- 状態: 仮置き・未検証。以下の具体化は検討用の仮説。

## 1. 元の案

- 生活習慣病や医療逼迫などの多方面の課題へのアプローチ
- 日々の生活習慣の見直しを行わせ、健康寿命を伸ばす。
- それぞれの年代にあった運動アプローチを行い長い人生を最後まで楽しくする。
- UIUXの工夫を行い、誰でもモチベーション高く続けられる工夫を行うべき

## 2. Why：誰の、どんな課題か

- カテゴリ候補: 医療・福祉
- 対象ユーザー・困る場面（仮説）: 運動したいが日常の中で継続できていない人。最初に対象とする年代・生活状況は未決定。
- 解決したい社会課題（仮説）: 運動習慣を続けにくいこと。生活習慣病や医療逼迫、健康寿命への影響は短期間の開発で実証したものとして扱わない。
- 根拠: 未確認。対象年代の生活・運動習慣に関する出典を調べ、対象者から続かない場面や理由を聞いて追記する。
- 人間が決める意図: 対象年代を絞り、本人に無理なく続けられる行動と継続の支え方を決める。

## 3. What：解決策と最小の体験

- 解決の仕組み（仮説）: 本人が決めた小さな運動目標を記録し、できなかった理由に合わせて次の取り組みを見直す。
- 操作フロー案: 目標と取り組む時間を決める→実施・見送りを記録する→振り返る→次回の目標を調整する。
- MVP候補: 1つの対象層、目標設定、実施記録、振り返り、続けやすい表示。
- 今回の対象外候補: 全年代への対応、診断・治療の提案、ウェアラブル連携、健康寿命の改善効果の断定。
- 既存の手段との差（仮説）: 一般的な記録アプリより、続かない理由を踏まえた見直しが役立つか検証する。

## 5. AIをどこで、なぜ使うか

- プロダクト内の利用案: 本人の記録の要約と、継続の障壁を振り返る問いの生成。
- その場面で使う理由: 一律の励ましより、本人の生活上の事情を整理することに役立つかを検証する。
- 人間が判断・確認すること: 対象者、問いの範囲、目標の変更、運動内容の扱い。AIに診断や無理な運動の指示をさせない。
- 開発支援の利用実績: 文書整理は[共通記録](README.md#この文書でのai利用)を参照。以降の利用は場面・理由・人間の判断を追記する。

## 6. 検証・完成度・デモ

- 課題と効果の検証: 対象者に複数日試してもらい、入力負担、取り組めた回数、見直しが役立った場面を確認する。結果は未検証で、長期の健康効果は別途検証が必要。
- UI・UXの確認: 対象年代の人が目標設定・記録・振り返りを完了できるか、見送りを選びやすいか確認する。
- 安全性・データの扱い: 体調や記録を必要以上に収集・公開しない。無理な継続を促さず、生成失敗時も記録を失わない設計を検討する。
- 拡張性・保守性: 対象層と記録項目を絞り、記録機能と生成部分を分けて変更できる構成を検討する。
- デモ構成案: 続かない具体的な場面→目標・記録→振り返りと調整→短期検証の結果と限界。
